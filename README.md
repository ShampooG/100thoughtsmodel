# 100个思维模型应用指南 (Mental Models App)

这是一个精心整理的 100 个核心思维模型应用指南网页应用，帮助你在工作、学习、决策、沟通与人生规划中高效思考。

## 项目特点

- 🧠 **内容丰富**：涵盖 10 大分类，共 100 个实用思维模型（包括解决什么问题、具体怎么做、实际案例等）。
- ⚡️ **纯静态构建**：无需任何前端构建工具（如 Webpack、Vite、Node.js 等），基于原生的 HTML5 / CSS3 / JavaScript 开发。
- 🚀 **简单易用**：界面简洁大方，响应式布局，支持快捷弹窗查看模型详情。
- 🌐 **部署方便**：支持一键部署至 GitHub Pages、Vercel 或 Netlify 等静态托管平台。

## 分类一览

## 本地运行

无需安装依赖，可以通过以下任意方式在本地运行：

1. **直接打开**：双击直接在浏览器中打开 `index.html` 文件即可使用。
2. **本地 HTTP 服务器**：在项目根目录下运行以下命令，然后在浏览器访问 `http://localhost:8000`：

   ```bash
   python3 -m http.server 8000
   ```

## 部署指南

### GitHub Pages

1. 将代码提交并推送至 GitHub 仓库。
2. 进入仓库设置 **Settings** -> **Pages**。
3. Source 选择 `Deploy from a branch`，分支选择 `main`（或 `master`），目录选择 `/ (root)`，点击保存即可。
